## Tecnologias Utilizadas
- **HTML5:** Estructura semántica moderna e interactiva (`<dialog>`, elementos nativos).
- **CSS3:** Variables personalizadas (`--root` y `[data-theme="light"]`), diseño responsivo, Flexbox y Grid.
- **JavaScript:** Manipulación del DOM, búsqueda y filtrado en tiempo real, persistencia con `localStorage` e interactividad del Quiz.
- **Git & GitHub:** Control de versiones profesional y despliegue continuo a través de **GitHub Pages**.
